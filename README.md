# Steam-Blocker
Yoooo, I made this bc I was on the game so much. Now, I can at least have the illusion of steam being locked. You can set your desired card count to be whatever you want. I put mine at 1000 bc I'm locked tf in. Whatever card count you decide on, it can only be changed every month. The app is called "SteamGate_v1" so obviously if you really wanted to hop on steam you could just end the program. But where's the fun in that? Also, I'm still working on the anki web syncing so you don't need to input your login to check your cards. It pulls from local save data. Enjoy and happy studying!
